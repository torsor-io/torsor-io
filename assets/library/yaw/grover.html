Tutorial 3: Grover search

yaw is a Python-based language for doing algebraic quantum programming. This tutorial explains how to perform Grover search, and discusses how qudit systems are treated in the language. We assume familiarity with prior tutorials: the introduction and teleportation.

1 Setup

In this tutorial, we'll be using qudits, the higher-dimensional cousin of qubits. These are natural for unstructured search, with a database of \(d\) objects corresponding to a qudit with \(d\) orthogonal states. We'll be using the algebraic approach, however, which is less familiar and requires some preparation.
